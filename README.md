# FBR Shop Survey

Android app for field surveyors: photograph a shop with a GPS / map / address / date stamp,
record CNIC, phone, business name, address and whether the shop is registered with FBR,
and export everything to Excel.

## Download

Latest APK: https://github.com/Tajmalookcs/fbr-survey/releases/latest/download/FBR-Shop-Survey.apk

Every push to `main` builds a new APK automatically (see the **Actions** tab).

## Features

- Camera photo stamped like a GPS map camera: map thumbnail, full address, coordinates, date & time
- Works offline: without internet the stamp shows coordinates and the address can be typed later
- Photos saved to Gallery → `FBR Survey`
- Records stored on the phone; tap to edit, long-press to delete
- Excel export (saved to `Download/FBR Survey` and shared via WhatsApp / email)
